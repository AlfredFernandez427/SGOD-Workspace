# **App Name**: SGOD Workspace

## Core Features:

- Chief Dashboard Overview: Dynamic display of key performance indicators (KPIs) like resources, assistance tickets, SBM compliance, and active projects, providing a high-level operational overview.
- Public Assistance Queue Management: Interface to view and track public assistance tickets, categorizing them by unit, status, and time for efficient management.
- Division Data & Analytics: Visual presentation of key divisional statistics and trends, such as projected enrollment and program impact, using concise charts and indicators.
- Active Infrastructure & Donations Tracker: Interactive display for monitoring active infrastructure projects and recent Division Partnerships and Donations for Schools (DPDS) entries.
- Planning & Research Repository: Centralized system for managing eBEIS data compliance, submitting and tracking research proposals (BERF), and monitoring research statuses.
- AI Chief Briefing Tool: Utilizes generative AI to synthesize real-time dashboard KPIs into high-level strategic briefings, identifying potential risks and suggesting prioritized actions for leadership.
- AI Research Abstract Generator Tool: Employs generative AI to draft academic research abstracts for proposals, based on user-provided problem statements, target participants, and proposed interventions.

## Style Guidelines:

- The color scheme is predominantly dark, providing a sophisticated and data-focused aesthetic.
- Primary color: A vibrant, deep blue (#3385FF), reflecting trust, professionalism, and innovation.
- Background color: A very dark, subtle blue-grey (#0A0E12), establishing a clean and immersive foundation.
- Accent color: A contrasting, yet harmonious violet-blue (#5C2AFF), used to highlight key interactive elements and provide visual dynamism.
- Font family: 'Inter' (sans-serif) will be used for all text elements, chosen for its modern clarity, excellent readability, and clean, objective aesthetic, suitable for both bold headlines and functional body text.
- Icons will adopt the minimalist, consistent line art style exemplified by 'Lucide' to maintain a sleek, modern, and universally understood visual language across the application.
- The application structure features a fixed left sidebar for primary navigation (with collapse functionality) and a fluid main content area. A sticky top header provides essential information and actions, ensuring constant access.
- Content sections will primarily utilize grid-based layouts to ensure a clear, organized, and easily scannable presentation of data, cards, and actionable items.
- Subtle and smooth transition animations will be implemented for UI elements such as sidebar expansion/collapse and hover states, enhancing user interaction without being distracting.
- Understated and functional animations will be used for loading states, particularly for AI processing, to provide clear visual feedback and manage user expectations.
